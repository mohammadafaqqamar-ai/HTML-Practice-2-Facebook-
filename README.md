# Facebook Login & Sign-Up Page – HTML Practice

## About the Project

This project is a simple Facebook-style login and sign-up page created as part of my Frontend Development learning journey.

The main purpose of this practice project was to improve my understanding of HTML by creating a webpage layout with login fields, sign-up forms, dropdown menus, and other HTML elements.

## Features

- Facebook-style blue header
- Login section with email and password fields
- Keep me logged in checkbox
- Sign-up form layout
- First name and last name fields
- Email and password input fields
- Gender dropdown menu
- Birthday dropdown menus for month, day, and year
- Image and text sections
- Table-based webpage layout

## Technologies Used

- HTML5
- Inline CSS
- Visual Studio Code

## HTML Concepts Practiced

While building this project, I practiced:

- HTML document structure
- Tables, rows, and columns
- Forms and input fields
- Text and password input types
- Checkboxes
- Select and option elements
- Images and text formatting
- Basic inline styling
- Page layout using HTML tables
